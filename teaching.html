关于热狗01开源智能车

热狗01是冷狼电子工作室推出的一款开源智能车训练底盘，基于 ROS2 开发，适合学习机器人导航、SLAM 建图、传感器驱动等核心技术。STM32 主控 + 树莓派上位机，搭载激光雷达、IMU、编码器里程计，支持 ROS2 Humble。

核心规格

  • 主控：STM32 运动控制 + 树莓派上位机（双核架构）
  • 系统：Ubuntu 22.04 + ROS2 Humble
  • 传感器：激光雷达 / IMU / 编码器里程计
  • 功能：底盘运动控制、SLAM 建图、Navigation2 自主导航
  • 形态：开源底盘，可二次开发与教学扩展

ROS2 基础指令教程

由冷狼电子工作室编写 · Ubuntu 22.04 + ROS2 Humble

1. 开发环境配置

sudo apt update sudo apt install ros-humble-desktop sudo apt install ros-humble-gazebo-ros-pkgs sudo apt install ros-humble-navigation2 sudo apt install ros-humble-slam-toolbox

2. 创建工作空间

mkdir -p ~/tute01_ws/src cd ~/tute01_ws colcon build source install/setup.bash

3. 底盘基础控制

# 前进 0.5m/s ros2 topic pub /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.5, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}" -1 # 原地左转 ros2 topic pub /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.5}}" -1

4. 传感器数据读取

ros2 topic echo /scan # 激光雷达 ros2 topic echo /imu # IMU 姿态 ros2 topic echo /odom # 里程计

5. SLAM 建图

ros2 launch slam_toolbox online_async_launch.py ros2 run nav2_map_server map_saver_cli -f ~/map

6. Navigation2 自主导航

ros2 launch nav2_bringup bringup_launch.py map:=~/map.yaml

在 RViz2 里用 “2D Goal Pose” 设目标点，小车自己规划路径。

7. Gazebo 仿真

ros2 launch tute01_gazebo tute01_world.launch.py
